# CineCircle Local App Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans in this session. The user has authorized implementation against the existing ER/SQL and frontend-design.

**Goal:** Deliver the local film community and cinema booking app described by CineCircle_Features.md.

**Architecture:** Vue browser application calls an Express JSON API using cookie sessions. The API accesses original MySQL tables through a connection pool and explicit transactions. Local visual/pricing configuration supplements fields absent from the schema.

**Tech Stack:** Vue 3, Vite, Vue Router, Express 5, mysql2, Node test runner, Playwright.

**Spec:** docs/superpowers/specs/2026-11-11-local-app-design.md

## Global Constraints

- Original SQL and ER image remain byte-identical.
- Bind app and development servers to 127.0.0.1; database via private local socket by default.
- No schema additions. All functional state persists in original tables.
- Local prices in HKD; timestamps interpreted as Hong Kong time.

## Review Focus

- Private lists and foreign-user writes must not leak or mutate data.
- Concurrent booking or partial failure must not sell seats twice or leave partial tickets.
- Query strings and route/body IDs must be validated and parameterized.
- Empty, loading, expired-login, failed-request, and mobile layouts must be usable.
- Startup/tests must not drop or reset existing user data or another MySQL service.
